# Security Policy

## Authorized Use Only
Raven is an autonomous penetration testing framework designed **strictly for authorized security testing**. 

By using Raven, you agree to the following conditions:
1. You must have explicit, written authorization to test the target system, network, or application.
2. You must define and respect the scope of your engagement.
3. You are solely responsible for any damage, disruption, or legal consequences arising from the use of this tool.

Raven is capable of deploying active payloads and generating significant traffic. It should only be used in controlled environments or against systems where you hold clear authorization.

## Limitations
- Raven does **not** guarantee complete vulnerability discovery. It is an automated tool and cannot replace a manual penetration test by skilled professionals.
- Some capabilities within Raven are experimental and may generate false positives or false negatives.
- Findings generated by the AI agent should always undergo human verification before remediation is attempted.

## Reporting a Vulnerability in Raven
If you discover a security vulnerability within the Raven framework itself, please do **not** open a public issue. Instead, please report it privately to the maintainers. We aim to address critical framework vulnerabilities as swiftly as possible.
