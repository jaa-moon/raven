### 3. subprocess with shell=True

**Severity:** 🟠 HIGH
**File:** `app.py`
**Location:** Line 35: output = subprocess.check_output(f"ping -c 1 {host}", shell=True)
**OWASP:** A03:2021 - Injection
**CWE:** CWE-78

**Description:**

`subprocess` called with `shell=True` passes the command to the OS shell interpreter. Any user-controlled content in the command string enables Command Injection (e.g. chaining commands with `;`, `|`, `&&`).

**Recommendation:**

Set `shell=False` and pass the command as a list of strings (e.g. `['ping', host]`). Validate and whitelist any user-supplied arguments.

### 4. f-string SQL Query Construction

**Severity:** 🟠 HIGH
**File:** `app.py`
**Location:** Line 24: query = f"SELECT * FROM users WHERE username = '{username}'"
**OWASP:** A03:2021 - Injection
**CWE:** CWE-89

**Description:**

An SQL query is being constructed using an f-string with variable interpolation. If any variable originates from user input, this is a SQL Injection vulnerability.

**Recommendation:**

Use parameterized queries or prepared statements. Pass user data as query parameters, never interpolate it into the SQL string. Example: `cursor.execute('SELECT * FROM users WHERE id = ?', (user_id,))`
